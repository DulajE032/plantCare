### Step 0.5 — Define Shared Types

#### [NEW] `src/lib/types.ts`

```ts
export interface DiseaseRecommendation {
  id: string;
  disease: string;
  slug: string;
  confidence: number;
  severity: "low" | "moderate" | "severe";
  description: string;
  causes: string[];
  treatment: string[];
  prevention: string[];
  cropType: string;
  imageUrl?: string;
}

export interface ScanResult {
  id: string;
  imageUrl: string;
  recommendation: DiseaseRecommendation;
  scannedAt: string;
}

export interface HistoryItem {
  id: string;
  thumbnailUrl: string;
  diseaseName: string;
  confidence: number;
  severity: "low" | "moderate" | "severe";
  scannedAt: string;
}
```

## Phase 3: Scan Page (Upload Flow)

> **Goal:** Get image in, compressed, and ready to send — mobile-first.

#### [NEW] `src/components/scan/ImageUploader.tsx`

- **Drag-drop zone** using `react-dropzone`:
  - Dashed border, icon, "Drag & drop your plant image here"
  - Accepts: `image/jpeg`, `image/png`, `image/webp`
  - Max 1 file
- **Two buttons below the drop zone:**
  - "📷 Take Photo" → `<input type="file" accept="image/*" capture="environment" />`
  - "🖼️ Choose from Gallery" → `<input type="file" accept="image/*" />`
- **On file select:**
  - Compress via `browser-image-compression` (maxSizeMB: 1, maxWidthOrHeight: 1024)
  - Show image preview with remove/retake button
- **State management:** `idle` → `selected` → `uploading`

#### [MODIFY] `src/app/scan/page.tsx`

- Layout: `ImageUploader` centered
- **Scan Tips Accordion** (shadcn `Accordion`):
  - "Use good lighting"
  - "Focus on the affected area"
  - "Include both healthy and diseased parts"
  - Mobile: collapsed below uploader; Desktop: sidebar
- **Submit button:**
  - Mobile: fixed to bottom of viewport (`fixed bottom-0`)
  - Desktop: inline below image preview
  - Disabled until image is selected
  - On click: POST to `/predict`, navigate to `/result/[id]`

**Deliverable:** Working upload UI, compressed image ready to POST to FastAPI `/predict`.

> [!IMPORTANT]
> **Backend Dependency:** This plan assumes a FastAPI backend will serve these endpoints:
> - `POST /predict` — accepts image, returns `ScanResult`
> - `GET /diseases` — returns list of `DiseaseRecommendation`
> - `GET /diseases/{slug}` — returns single `DiseaseRecommendation`
> - `GET /history` — returns list of `HistoryItem`
>
> **Do you already have this backend, or should I plan mock-data-only mode for now?**

> [!NOTE]
> **Design decisions baked in:**
> - shadcn/ui `Skeleton` component used everywhere — no spinners, ever
> - `RecommendationPanel` is built once and reused on Result page + Disease Detail page
> - Bottom tab bar on mobile replaces nav links (no hamburger menu on mobile *for navigation*, only for overflow)
> - localStorage for history in Phase 6, swapped to API in Phase 7
> - All images compressed client-side before upload (maxSizeMB: 1)
